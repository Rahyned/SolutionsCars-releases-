# SolutionsCars

**Sistema de gestión de escritorio para un taller mecánico, de GNC y lubricentro: clientes, stock, vencimientos y facturación electrónica.**

El código fuente es privado. Podés ver cómo funciona en el [caso de estudio](https://lautaro.is-a.dev/proyectos/solutionscars).

## Qué resuelve

El taller manejaba stock, facturas y vencimientos a mano. SolutionsCars lo concentra en un sistema que usa todos los días.

## Funcionalidades principales

- Clientes y vehículos.
- Inventario y recepción de vehículos.
- Vencimientos de obleas de GNC, con avisos por WhatsApp y email.
- Facturación electrónica con ARCA, en producción.

## Stack

Python · Flet · SQLAlchemy + Alembic · SQLite (PostgreSQL opcional) · pyafipws · ReportLab · pytest · GitHub Actions (100 % de cobertura).

## Estado

En uso diario desde marzo de 2026. Versión actual: 2.3.21.
